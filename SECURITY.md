# Safety and security

This repository documents a hobbyist process that modifies PS3 boot-related configuration. Incorrect steps can cause data loss or make recovery difficult.

## Reporting a problem

For documentation errors or unsafe instructions, open an issue with the affected section and a reference to reliable supporting documentation. Do not publish console identifiers, account information, credentials, private keys, or flash backups in public issues.

If a report contains sensitive information, remove it from the issue and use GitHub's private reporting options if they are enabled for this repository.

## Important

- Back up user data and the console's NAND or NOR flash before changing boot-related settings.
- Never assume that a recovery method works for every NAND/NOR model.
- Only use files from sources you trust and verify compatibility with your exact CFW and console.
- This repository is not an official Sony or Evilnat project.
