# Contributing

Contributions that improve the accuracy, clarity, or safety of this guide are welcome.

## Before opening an issue or pull request

- Check that your information applies to the PS3 model and Evilnat CFW version you are describing.
- Include links to reliable documentation or upstream sources where possible.
- Separate personally tested behavior from assumptions or reports from other users.
- Do not recommend steps that may erase data or modify flash without a clear warning.
- Never include console IDPS, PSID, account credentials, private keys, or other identifying secrets in an issue.

## Pull requests

Keep changes focused and explain what was changed and why. For hardware-specific findings, include the console model, CFW version, Petitboot build or source, Linux distribution, and installation target when relevant.

This repository is a community guide, not official Sony or Evilnat support. Compatibility reports are helpful, but they should not be presented as universal results unless verified.
